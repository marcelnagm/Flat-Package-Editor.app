# Flat Package Editor.app

Cópia do aplicativo **Flat Package Editor** para macOS (bundle `com.apple.installer.tools.FlatPackageEditor`, versão 1.0), ferramenta usada para abrir e inspecionar pacotes de instalação *flat* (`.pkg`): ver o conteúdo do arquivo XAR, o BOM e editar os arquivos de texto internos.

## Importante

- Este repositório **não contém código-fonte**, apenas o bundle `.app` já compilado.
- O aplicativo **não foi criado por mim**; ele faz parte das ferramentas de desenvolvedor da Apple e pertence aos seus autores. O repositório serve só como arquivo pessoal de backup.
- Como é um binário distribuído fora da fonte oficial, prefira obter a ferramenta pelos canais da Apple.

## Uso

```bash
git clone https://github.com/marcelnagm/Flat-Package-Editor.app
open "Flat-Package-Editor.app/Flat Package Editor.app"
```

O macOS pode bloquear a abertura na primeira vez (Gatekeeper); nesse caso use *Ajustes do Sistema → Privacidade e Segurança → Abrir mesmo assim*.
